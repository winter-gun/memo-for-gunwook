# 메모 한눈에

여러 줄 메모를 한 줄마다 하나의 할 일로 정리하는 개인용 웹앱입니다. LLM, 외부 추론 API, 계정 로그인, 서버 데이터베이스 없이 브라우저에서 동작합니다.

## 기능

- 한 줄을 한 할 일로 정리하며 빈 줄을 건너뜁니다.
- 날짜는 직접 지정할 때만 저장합니다. 본문의 ‘내일’ 같은 표현을 날짜로 추론하지 않습니다.
- 완료·미완료, 카드·표 보기, 검색, 수정, 삭제·되돌리기를 지원합니다.
- PNG 이미지 저장과 JSON 백업·가져오기를 지원합니다.
- 같은 제목도 별개의 항목으로 보존합니다.
- 유니코드 줄바꿈과 조합형·완성형 검색을 처리하며 이모지와 저장 원문은 유지합니다.

## 저장과 백업

메모는 사용 중인 기기·브라우저 프로필의 localStorage에 저장됩니다. 다른 사람의 기기에서는 그 사람의 저장소를 사용하므로 메모가 하나의 공용 목록에 모이지 않습니다. 같은 기기·같은 브라우저 프로필을 함께 쓰면 같은 메모가 보일 수 있습니다. 기기 간 자동 동기화는 없습니다.

GitHub Pages의 같은 계정 아래 프로젝트들은 같은 출처(origin)를 공유합니다. 이 앱은 우연한 키 충돌을 줄이기 위해 `memo-for-gunwook.local.v1`이라는 전용 저장 키를 사용합니다. 이 키는 같은 출처의 다른 앱 코드에 대한 보안 격리를 제공하지는 않습니다.

주소가 바뀌면 기존 메모는 자동 이동하지 않습니다. 기존 환경에서 **백업 → 내 메모 백업하기**로 저장한 JSON을 새 주소에서 가져오세요. 가져오기는 기존 목록과 병합하고 같은 ID는 건너뛰어 현재 항목을 오래된 백업으로 덮어쓰지 않습니다. 저장소·브라우저 데이터 삭제 전에도 백업을 보관하세요.

## GitHub Pages 배포

이 저장소의 `main` 브랜치 `/docs` 폴더가 배포 대상입니다. GitHub Free에서 공개 저장소의 Pages를 사용하며 유료 도메인이나 서버를 사용하지 않습니다.

Python 3으로 정적 파일을 만듭니다. 별도 패키지 설치는 필요하지 않습니다.

```bash
python build.py
```

`docs/`의 HTML·manifest·service worker·아이콘과 `.nojekyll`을 커밋하면 GitHub Pages가 게시합니다. 파일과 서비스워커 범위는 상대경로를 사용해 프로젝트 하위 경로에서 동작합니다.

## 검증

고정 난수 시드 `20261020`의 10개 예외 입력 시나리오와 기존 24개 회귀 테스트를 포함합니다. GitHub Pages 배포에서는 저장 키 충돌 방지와 하위 경로의 파일 해석도 추가 확인했으며, 총 36개 테스트 통과·실패 0개를 확인했습니다.

```bash
node --test test-memo-core.cjs test-app-storage.cjs test-cycles.cjs test-pwa.cjs test-input-fuzz.cjs test-github-pages.cjs
```

일부 자동 검증은 실제 앱 코드를 VM과 간단한 DOM 모형에서 실행합니다. 실제 아이폰 Safari 설치·비행기 모드·iOS 공유 메뉴의 실기 검증을 모두 완료한 것은 아닙니다. 여러 탭의 지연된 변경 알림을 처리하지만 모든 동시 쓰기를 원자적으로 보장하는 공동 편집 기능은 아닙니다.
