메모를 가볍게 정리하는 방법

가입이나 로그인 없이 사용하는 나만의 메모 보드입니다.
LLM 없이 직접 작성한 규칙으로 정리하고, 이 기기에 저장합니다.

01 · 한 줄에 하나씩 적기

여러 줄을 붙여넣으면 한 줄씩 메모가 됩니다. Ctrl + Enter로도 추가할 수 있어요. 한 문장 안의 여러 일을 의미로 나누는 AI 기능은 사용하지 않습니다.

02 · 날짜는 정했을 때만

기본값은 날짜 없음입니다. ‘내일’, ‘다음 주’ 등의 문구를 적어도 날짜를 자동 지정하지 않아요. 날짜 추가에서 직접 선택하세요.

03 · 끝냈다면 체크

오른쪽 위 체크 상자를 누르면 완료 목록으로 이동합니다. 다시 누르면 미완료로 돌아옵니다. 메모 제목이나 연필 버튼을 누르면 내용을 수정할 수 있어요.

04 · 내 방식으로 보기

카드와 표는 같은 메모를 보여줍니다. 날짜가 없는 메모도 계속 남습니다. 이미지 저장에서 현재 검색·분류 결과를 미리 보고 PNG로 보관할 수 있어요.

05 · 백업으로 오래 보관하기

백업 파일에는 완료 상태, 날짜, 내용이 함께 담깁니다. 가져올 때 현재 목록은 유지하고, 같은 고유번호의 메모는 건너뜁니다. 백업은 과거 상태로 덮어쓰는 복원 기능이 아닙니다.

자동 저장은 이 브라우저의 저장 공간을 사용합니다. 브라우저 데이터 삭제, 시크릿 모드 종료, 다른 브라우저·기기 사용, 앱 주소 변경에 대비해 백업 파일을 보관해 주세요. 주소를 바꾸기 전 이전 주소에서 백업하고 새 주소에서 가져오세요. 기기 간 자동 동기화는 없습니다. 자동 저장이 차단되면 화면에 안내합니다.

직접 학습하려면 HTML 소스나 함께 만든 소스 파일을 편집기로 여세요. CSS는 화면을, MemoCore는 줄 분리와 데이터 검증을, 앱 코드는 저장·수정·화면 갱신을 담당합니다. 별도 학습 모델을 포함한 파일은 아닙니다.

아이폰에서 앱처럼 사용하기

홈 화면에 아이콘을 두면 메모를 더 쉽게 꺼내 볼 수 있어요.

  1. 이 페이지를 Safari로 열기다른 앱 안에서 보고 있다면 Safari에서 다시 열어 주세요.
  2. 공유 → 홈 화면에 추가Safari의 페이지 메뉴 안에 공유 버튼이 있을 수도 있어요.
  3. ‘웹 앱으로 열기’를 켜고 추가이 항목이 있는 경우 켜 주세요. 홈 화면의 ‘메모 한눈에’ 아이콘으로 열면 됩니다.

오프라인 사용 준비를 확인하고 있어요.

처음에는 인터넷에 연결해 홈 화면 앱을 한 번 열어 주세요. ‘오프라인 준비 완료’가 표시된 뒤에는 메모를 인터넷 없이 작성할 수 있어요.

메모는 앱을 연 기기 안에 저장됩니다. Safari와 홈 화면 앱 사이에서 목록이 다르게 보이면 ‘백업 → 가져오기’로 옮겨 주세요. 기기 변경이나 브라우저 데이터 삭제 전에는 백업 파일을 보관하세요.
